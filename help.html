Sistem Informasi Serah Terima Alat - CSSD

Panduan Penggunaan SISTA CSSD

Aplikasi SISTA-CSSD adalah sistem cerdas berbasis serverless yang mengintegrasikan pemindaian QR Code kamera, tracking siklus sterilisasi 7-tahap, kontrol etalase FEFO, awarding kinerja staf, dan notifikasi otomatis multi-channel untuk mendukung akreditasi paripurna rumah sakit.

Masuk Aplikasi

1. Ekosistem Fitur Canggih

Mengapa SISTA-CSSD menjadi pelopor digitalisasi logistik steril rumah sakit.

Scan QR Kamera Cepat

Integrasi pemindaian kamera HP secara langsung. Cukup arahkan kamera pada label QR alat medis untuk melihat isi set, status sterilisasi, masa aktif, serta langsung memproses penyerahan/pengembalian instan.

Kontrol Etalase & Rotasi FEFO

Admin CSSD dapat mengontrol tombol Pajang/Hidden (👁️/🙈) pada katalog ruangan untuk memastikan rotasi rotasi barang *First Expired, First Out* (FEFO) berjalan disiplin dan mencegah instrumen kadaluwarsa dini.

Modus Layar Luas & Ringkas List

Pengguna dapat menyembunyikan sidebar navigasi desktop (☰) serta memilih mode tampilan Katalog **Ringkas (List Mode 📑)** yang memuat 15–30 data sekaligus dalam 1 layar tanpa *scrolling* panjang.

Sistem Prestasi Staf 🏆

Menghadirkan fitur gamifikasi kerja. Staf CSSD mendapatkan akumulasi poin otomatis untuk setiap aksi sterilisasi, penyiapan alat, dan pencatatan. Dilengkapi halaman podium interaktif 3 besar teraktif bulanan.

Tracking 7-Siklus CSSD

Mengontrol status posisi instrumen medis secara komprehensif mulai dari 1. Kotor, 2. Pencucian, 3. Setting, 4. Labelling/Packing, 5. Proses Sterilisasi, 6. Steril, hingga 7. Penyimpanan.

Maintenance Mode Enterprise 🛠️

Super Admin dapat mengaktifkan mode pemeliharaan server secara resmi. Halaman login Google SSO tetap terbuka, dan pesan pengumuman maintenance yang elegan akan tampil setelah login untuk pengguna biasa.

2. Siklus Pemrosesan Alat Medis (7 Tahapan CSSD)

Gambaran siklus perputaran instrumen steril secara disiplin di rumah sakit.

1

Kotor

Alat pasca-tindakan medis dari ruangan dikembalikan ke CSSD dalam kondisi kotor.

2

Pencucian

Dekontaminasi, pencucian dengan cairan khusus enzimatis, pembilasan, dan pengeringan.

3

Setting

Penyusunan instrumen medis ke dalam set wadah steril dan pengecekan kelayakan alat.

4

Labelling/Packing

Pengemasan set alat menggunakan pembungkus steril dan pemasangan indikator kimiawi serta label QR Code.

5

Proses Sterilisasi

Proses pembunuhan kuman di dalam mesin Autoklaf (suhu tinggi) atau Plasma (suhu rendah).

6

Steril

Alat medis telah selesai melalui proses sterilisasi fisik dan dipastikan indikator kimianya berubah warna secara sempurna.

7

Penyimpanan

Alat disimpan di ruang steril khusus. Alat **hanya dapat dipinjam ruangan** jika diset status etalase `ON` oleh Admin.

💡 Catatan Transaksi: Ketika ruangan berhasil meminjam alat berstatus "Penyimpanan", status posisi alat akan otomatis berpindah menjadi "Dipinjam [Nama Ruangan]". Saat alat dikembalikan oleh ruangan ke CSSD, statusnya langsung diset kembali menjadi "Kotor" untuk mengulang siklus 7-tahap di atas.

3. Panduan Staf Ruangan / Unit Kerja

Petunjuk lengkap bagi unit peminjam alat sterilisasi medis.

Fase 1

Registrasi Cepat Berbasis Ruangan

Gunakan akun Google SSO Anda. Jika email Anda belum terdaftar, isi nama Anda, pilih ruangan Anda (klik Lainnya untuk mengetik ruangan baru), dan nomor HP/WhatsApp. Setelah mengklik kirim, notifikasi aktivasi dikirimkan ke Admin CSSD untuk persetujuan.

Fase 2

Mengajukan Peminjaman & Fitur Pembatalan (Batal Order)

Pada menu Katalog Alat, Anda dapat memilih mode tampilan **Ringkas (List Mode 📑)** untuk memuat puluhan item sekaligus dalam 1 halaman. Klik + Request, buka tab Keranjang Request, lalu kirimkan permintaan.

✨ Fitur Pembatalan Pesanan: Jika Anda salah mengeklik barang yang dipinjam, Anda dapat membuka tab Riwayat & Status dan mengeklik tombol Batal Order selama status pesanan masih Pending. Barang yang dibatalkan akan otomatis dikembalikan ke stok penyimpanan CSSD tanpa membuat catatan barang kurang/rusak.
Fase 3

Modus Layar Luas (☰) & Detail Rincian Alat

Untuk mendapatkan tampilan tabel yang sangat luas di layar komputer, klik **Tombol Menu Hamburger (☰)** di bagian kiri atas header. Sidebar navigasi akan tersembunyi sehingga area kerja meluas 100% penuh. Klik pada **Nama Alat** mana saja di katalog atau riwayat untuk membuka pop-up detail berisi foto HD, komponen rincian set, dan status sterilisasi.

4. Panduan Petugas (Admin & Super Admin CSSD)

Tata cara pengelolaan etalase, pemrosesan transaksi, dan maintenance server.

Modul Admin

Sistem Kontrol Etalase (Tampilkan/Sembunyikan 👁️/🙈)

Buka tab Inventaris Alat. Pada kolom *Etalase*, Admin dapat mengklik tombol toggle untuk mengubah status tampilan alat:

  • Dipajang (ON 👁️): Alat medis berstatus Penyimpanan dapat dilihat dan dipinjam oleh ruangan di Katalog.
  • Sembunyi (OFF 🙈): Alat medis disembunyikan dari Katalog Ruangan (misalnya untuk mengontrol rotasi FEFO atau menyimpan alat cadangan agar alat lama dihabiskan terlebih dahulu).
Modul Admin

Manajemen Maintenance Mode (Super Admin Only)

Pada tab Pengaturan, Super Admin dapat mengaktifkan atau mematikan **Maintenance Mode (ONLINE / MAINTENANCE)** dan mengubah pesan pengumuman server. Saat mode aktif, pengguna umum yang login akan diarahkan ke halaman maintenance resmi, sementara Super Admin dapat melakukan *Bypass* otomatis untuk pengujian sistem.

Modul Admin

Evaluasi Kinerja Staf & Akumulasi Poin Prestasi

Setiap petugas CSSD yang terdaftar di sistem akan mendapatkan poin otomatis setiap kali memproses transaksi logistik steril:

+10 Poin Menyelesaikan Sterilisasi Alat (Set Steril)
+5 Poin Melakukan Konfirmasi Serah Terima ke Ruangan
+5 Poin Memproses Konfirmasi Pengembalian Selesai

Perolehan poin bulanan dikompilasi secara real-time pada tab Prestasi Staf 🏆, lengkap dengan visualisasi podium 3 besar, ekspor berkas Excel (.xlsx), dan cetak PDF resmi A4 lengkap dengan Kop Surat RSUD.

5. Pertanyaan Umum (FAQ)

Jawaban cepat atas pertanyaan operasional yang paling sering diajukan.

Q: Apakah pengguna ruangan dapat membatalkan pesanan jika salah memilih barang?

Ya! Selama status peminjaman di tab Riwayat & Status masih Pending (belum disetujui petugas CSSD), Anda dapat mengeklik tombol Batal Order. Alat yang dibatalkan akan otomatis dikembalikan ke stok Penyimpanan CSSD tanpa menimbulkan status barang rusak/kurang.

Q: Mengapa suatu alat steril di ruang Penyimpanan CSSD belum muncul di Katalog Ruangan?

Petugas CSSD menerapkan sistem kontrol etalase FEFO (First Expired, First Out). Alat medis yang baru disterilkan dapat disembunyikan sementara (`OFF`) dari katalog oleh admin agar ruangan meminjam stok alat steril lama yang kedaluwarsanya lebih awal terlebih dahulu.

Q: Bagaimana jika website SISTA-CSSD sedang dalam pemeliharaan (Maintenance Mode)?

Anda dapat tetap melakukan login dengan Google SSO. Jika sistem sedang dalam masa pemeliharaan (`ON`), Anda akan disajikan Halaman Maintenance resmi yang berisi pengumuman estimasi waktu selesai, tombol pintasan WhatsApp Admin CSSD, dan tombol Keluar.

Q: Bagaimana cara memuat puluhan item katalog sekaligus agar lebih cepat dibaca?

Di menu Katalog Alat, ubah mode tampilan dari Grid menjadi Ringkas (List Mode 📑) dan pilih opsi Muat: 36 / hal atau 100 (Semua) pada dropdown per halaman.
